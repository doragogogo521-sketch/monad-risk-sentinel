# Agent / 数据同学：接入任务

本目录包含一个固定模拟报告样例，不包含真实 Agent 服务。前端当前自行生成同结构报告；尚未从此文件自动加载，也未接入HTTP API。

先对齐 [联调基准 v1](../docs/联调基准-v1.md) 与 [报告 Schema](../frontend/report.schema.json)。样例见 [examples/risk-report.simulated.json](examples/risk-report.simulated.json)。

## 最小交付

1. 一个固定、可重复的制度风险事件 replay 输入；真实来源需可追溯，模拟来源必须标记simulation。
2. 结构化报告：事件类型、地区、机构、时间、来源、可信度、证据、关系路径、市场与协议敞口、风险判断、有效期、建议动作。
3. 每段关系必须关联证据；无明确资产关联只输出WATCH，不能从宏观新闻推断某稳定币储备。
4. 明确分数与证据门槛。ORANGE/RED不能仅靠模型措辞升级；当前80/75/57只是未校准样例。
5. 提供服务启动方式或回放脚本、报告获取方式及错误返回样例。若采用API，请说明URL、请求/响应、加载与失败状态、是否需要服务端鉴权。

## 与前端约定

- Unix秒、bps、0–100分数；真实资产地址由部署提供。
- 报告保留schemaVersion、simulation、relations和limitations；不能把模拟材料变成真实证据。
- 样例的时间戳是历史快照，不代表当前仍有效；实际回放需重新生成时间和TTL。
- 哈希算法与序列化格式必须和合约同学统一。样例JSON不包含自身哈希；前端模拟使用SHA-256(JSON.stringify(report))。
- 发布私钥放在受控后端或钱包，不进入仓库和前端。报告不得包含密钥、助记词或私人资料。

## 可延后

复杂实时新闻抓取、多资产覆盖、质押挑战与自然语言润色。先完成可信事件回放和链上闭环。
