# 启动与演示

## 本地运行

从仓库根目录运行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory frontend
```

Windows可用 `py -3` 替换 `python3`。然后打开 http://127.0.0.1:8765/ ，保持终端运行。

- 点击开始引导演示。先展示GREEN下75%的LTV以及成功借款。
- 展示三份模拟证据，说明“机构变化→托管关系→稳定币→借贷池”的路径。
- 回放ORANGE事件，展示75%→45%，以及理论额度与策略实际可借额度的区别。

需要完整重演时点击右上角重置，或重新开始引导。

## 常见问题

- 页面打不开：服务终端需要持续运行。localhost只对运行服务的这台电脑有效，不能转发给队友使用。
- 端口占用：换8766，同时修改浏览器地址。
- 看到旧内容：刷新；必要时强制刷新。
- 哈希生成失败：使用localhost或HTTPS，避免直接打开file路径。
- 提取失败：检查当前债务和LTV；还款后再提取，不能把“允许退出”理解成无抵押约束。
- 不能新增借款：ORANGE、RED、UNKNOWN按策略禁止，即使理论额度大于零。
- 找不到钱包连接：当前是模拟版本，尚未加入钱包或链上调用。
